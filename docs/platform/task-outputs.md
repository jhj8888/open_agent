# 任务产物

任务详情的“任务产物”展示已登记文件、大小、SHA256、生成步骤和归档状态。文本、Markdown、CSV、JSON、日志、YAML 可进行纯文本预览；其他格式作为附件下载。浏览器下载时再次核对 SHA256。HTML/SVG 不在平台源内执行。

Agent 将交付文件写到 `/workspace/outputs/`。DeepAgents 的工具完成后，可信执行器归档当前输出；最后结束前再检查一次。StateBackend 的文件也进入相同归档流程，无需沙盒。每个任务仍独立并发，同一任务的工具和归档按序执行，避免后一工具覆盖尚未归档的交付物。

文件保存在现有私有 S3 对象存储的独立 `task-outputs/v1/` 前缀，MySQL 保存引用和摘要。已发布文件不设置自动到期，不随沙盒销毁、任务结束或日志/trace TTL 删除。相同路径、相同内容幂等；相同路径、不同内容保留不同记录。旧任务没有归档过的文件不会被虚构补齐。

列表、预览、下载复用任务读取权限，包括部署凭据只能访问自己的任务、生产委托访问范围与当前成员状态。下载时重新检查权限并记录审计；API 不接收任意对象键或公开存储链接。

默认配额为每文件 32 MiB、每任务最多 32 个内容版本且累计 128 MiB、每租户每环境 2 GiB。租户环境额度由 `platform.outputs.max-tenant-bytes` 配置。容量不足会拒绝新归档，已有文件保持可用。失败/取消任务展示已归档的部分产物；未写完或尚未成功归档的内容不承诺可恢复。归档失败不会显示可下载的假链接。

上传记录先持久化，完整写入、摘要验证、有效租约复核后才发布。失败上传有独立不可变对象键；超过 15 分钟且没有已发布引用的候选对象，由对账作业按确切记录清理。已发布对象不进入该作业。

当前接口：

| 操作 | HTTP 路径 |
| --- | --- |
| 文件列表 | `GET /api/v1/runs/{runId}/outputs` |
| 文本预览 | `GET /api/v1/runs/{runId}/outputs/{outputId}/preview` |
| 授权下载 | `GET /api/v1/runs/{runId}/outputs/{outputId}/download` |

备份需同时覆盖任务、`oa_run_output`、`oa_run_output_upload`、`oa_run_output_access` 及 S3 内容，恢复时重新校验摘要和引用。完整删除墓碑流程、备份恢复演练属于后续验收项；本功能不会自动删除任何已有任务或已发布文件。
