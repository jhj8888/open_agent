# 展示版本验收与操作

展示入口：<https://120.26.81.83/open-agent/>。绿色与白色工作台使用真实后端、真实模型响应和持久任务记录。

## 建议体验顺序

1. 使用展示账号登录，选择“演示租户 / 测试环境”。`demo` 管理配置与成员，`publisher` 负责生产发布；凭据通过本机私有记录交付，不存入仓库。
2. 在 Skill 资源库查看 `meeting-notes` 的 `SKILL.md`、`references/template.md`、文件摘要和固定版本。源码位于 `examples/skills/meeting-notes/`，ZIP 根目录应直接包含这两个路径。
3. 在 Agent 工作台打开“会议纪要 Skill 助手”的聊天调试。任务历史中的 `5e3145f9` 是实际执行示例；可输入自己的合成会议记录创建新的独立任务。
4. 在任务中心查看状态、日志、Token 用量。关闭聊天不会取消任务，重新打开可继续查看；需要中止时使用“取消任务”。
5. 在“发布与 API”中查看固定部署的 HTTP 地址和请求样例。生产推广需要该版本成功运行且资源已核验回收，并由获授权发布人员操作；生产执行权限与发布权限分别控制。

6. 在“监控概览”选择最近 1 小时、24 小时或 7 天，查看当前租户/环境的全部保留任务、用量、耗时及资源占用。平台管理员还可查看主机 CPU、内存、磁盘和组件状态；页面每 30 秒刷新，数据失效时明确显示不可用。

每次发送创建独立任务，当前聊天窗口不是自动延续全部历史上下文的长期会话。监控使用数据库窗口聚合；Agent 首页的最近任务卡片仍受每个部署最近 50 条的列表范围限制。

## 已核验的会议纪要示例

通过浏览器完成 ZIP 上传、文件预览、选择固定 Skill/模型版本、创建部署和聊天提交。输入使用虚构记录，结果按模板分别列出摘要、决策、行动项和待确认信息，没有补充日历日期或缺失负责人。任务 `5e3145f9-4559-4f9d-add5-1636eafbdd9b` 成功，页面记录 28.3 秒、12,962 Token、296 条事件；后端事件序号唯一且有序，Temporal 完成，进程/cgroup、沙盒、执行配额均已释放。详见 `meeting-notes-verification-20261105.json`。

## 登录和新用户接入

令牌刷新由官方 oidc-client-ts SDK 完成，并发请求只执行一次刷新。刷新凭据过期时清理内存身份并返回登录入口，不自动重放提交操作；身份服务暂时不可用时保留会话供后续重试。5 项定向测试验证这些行为。

企业身份服务创建或接入账号后，用户首次进入工作台调用 `POST /platform/profile` 幂等登记本地资料。页面先登记再查询租户。无租户用户可将页面所示账号标识交给管理员；管理员显式分配租户、环境和角色。登记不创建租户、成员或管理员权限，也不会重新激活禁用/删除账号。旧记录资料保持不变，大小写或重音排序冲突会被拒绝。

身份入口复用 [Spring Security JWT 资源服务器](https://docs.spring.io/spring-security/reference/servlet/oauth2/resource-server/jwt.html)，没有另写令牌解析/校验。幂等插入使用 [MySQL 官方唯一键冲突机制](https://dev.mysql.com/doc/refman/8.4/en/insert-on-duplicate.html)，重复项不修改资料，随后逐字核对 subject。Context7 当前不可用，使用上述官方文档与已安装依赖验证 API。

实机新增 `member-demo` 账号，先验证零权限登记与浏览器账号标识，再通过管理员治理 API 创建“权限验收租户”，仅赋予测试环境管理员角色。浏览器“刷新租户”后仅显示该租户，生产环境明确未授权。13 项公开 HTTPS 检查拒绝跨租户模型、Skill/文件、部署、成员、审计、任务/事件，以及伪造身份和未授权生产访问；平台管理员亦不会自动成为该租户业务成员。该测试账号不拥有主“演示租户”的权限。

## 保留的交付边界

展示服务器使用 gVisor 与单机 Temporal 开发服务。生产 Skill 执行要求 Kata；企业 K8S、完全离线冷启动、备份恢复、生产监控集成和容量压测继续按 OpenSpec 验收。不能把展示机业务闭环视为这些生产条件已全部完成。
