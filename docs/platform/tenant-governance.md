## 管理操作

- 平台管理员可创建租户，指定已登录登记的负责人；负责人获得测试管理员权限，生产权限仍需单独登记。没有任何租户时，平台管理员也可从空页面创建首个租户。
- 平台管理员可暂停、恢复租户。已归档租户不能恢复。暂停后页面禁用成员、配额及管理员登记；获授权管理员仍能查看配额和审计。
- 活动租户的环境管理员可添加、调整、移除当前环境成员。移除或降级最后一位可用管理员会被拒绝；已禁用账号或已离开旧空间的账号不能充当保底管理员。
- 配额显示上限以及当前排队、未释放执行槽、未释放沙盒数。执行槽包含待回收资源。降低上限不会强制释放已有资源；准入继续使用任务账本的原子检查。
- **每日 Token 预算目前只保存配置，尚未自动执行限额。** API 返回 `tokenBudgetEnforced=false`，页面明确提示；不能据此承诺预算限制已经生效。

## 审计查询

`GET /platform/tenants/{tenant}/environments/{environment}/audit` 保留数组响应，支持精确 `action` 筛选和 `beforeId` 分页。每页最多 100 条；每项新增十进制字符串 `cursor`，末项 `nextBeforeId` 为下一页游标，无下一页时为 null。客户端使用字符串游标，避免 JavaScript 大整数精度损失。原数字 `id` 仅为兼容保留。

每次查询重新检查租户、环境和角色；游标不代表授权。页面提供上一页、下一页、刷新最新和变更前后详情。展示文本来自既有审计，未记录的旧值显示“无记录”，不补造历史。模型、凭据等记录仍遵循各业务服务的脱敏规则。

`retainUntil` 是至少保留到的时间。调整审计保留天数只影响新记录，不缩短已有记录；当前没有因为该时间到期而自动删除审计的功能。
