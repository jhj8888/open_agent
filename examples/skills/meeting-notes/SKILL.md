# 会议纪要整理

用户提供会议记录、转录文本或讨论要点时使用此 Skill。

1. 阅读用户提供的内容，区分已经达成的决策与尚未确定的建议。
2. 按 `references/template.md` 的格式输出，保留关键事实与分歧。
3. 行动项必须来自原文。缺少负责人或截止时间时填写“待确认”，不能猜测。
4. 不主动发送邮件、不修改外部系统、不访问外网。
5. 在末尾列出需要用户补充的信息；没有待确认项时注明“无”。

本 Skill 只需要读取模板和整理文本，不需要执行 Shell 或 Python。
