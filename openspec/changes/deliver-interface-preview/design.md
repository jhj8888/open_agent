# Design

## Context

现有执行底座已分阶段验证，统一 HTTP API 和完整控制台仍在集成。用户需要尽快看到整体效果。

## Decisions

1. 新增 `console/frontend/preview` 和独立 Vite 配置，复用已有 React/Vite 依赖，不改主控制台路由或认证。没有新增运行时 npm 依赖。
2. 数据为合成示例；所有页面持续显示提示，模拟回复明确标注。刷新恢复初始数据，取消操作防止完成定时器覆盖取消状态。
3. 租户/环境切换仅是界面演示，不声称实际授权隔离。真实生产部署、上传和发布仍由其已有 OpenSpec 变更负责。
4. 静态服务使用 Python 标准库 HTTPServer 的有限扩展：资产白名单、无目录列表、24 个并发连接上限和超时。仅用于短期公开静态评审；生产沿用企业网关。CSP 禁止网络连接，页面不接收任何真实凭据。
5. 授权服务器独立目录、回环端口、非登录用户、受限 systemd unit；校验制品 SHA-256，保留历史目录。更新失败时恢复原 unit。公网端口 18080 不通时，使用已核验的现有静态文件入口挂载项目专属链接，不修改现有应用代码/配置、不重启应用、不修改 Docker 或防火墙。

## Verification

构建与 TypeScript 检查，外部 HTTP 获取，浏览器检查导航、创建示例 Agent、模拟任务完成与取消、租户环境切换。验收结果写入 `docs/platform/interface-preview.md`。
