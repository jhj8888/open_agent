# Spec Delta

## Purpose

现有 Skill 编辑会修改当前文件，运行中任务难以复现，测试和生产也缺乏明确的不可变制品边界。需要将 SKILL.md、脚本及资源组成有摘要的版本，并以同一版本完成测试、推广和回滚。 本能力用于定义企业内网 Agent 平台的可验证行为边界，使测试、部署、失败处理和权限控制具有一致的验收依据。

## ADDED Requirements

### Requirement: 不可变发布制品

系统 SHALL 将 SKILL.md、脚本和资源发布为带内容摘要的不可变版本。

#### Scenario: 发布成功

- **WHEN** 合法包完成上传和内容核验
- **THEN** 生成可引用 release_id 和完整 manifest

#### Scenario: 禁止修改

- **WHEN** 用户尝试覆盖已发布版本的文件
- **THEN** 拒绝覆盖并要求创建新版本

### Requirement: 任务固定版本

系统 SHALL 在任务接入时固定所需 Skill 版本，并使草稿修改不影响已接入任务。

#### Scenario: 运行中修改草稿

- **WHEN** 任务引用版本 V1 后用户编辑草稿
- **THEN** 任务仍使用 V1，运行记录可查摘要

#### Scenario: 版本越权

- **WHEN** 用户指定其他租户的 release_id
- **THEN** 拒绝接入且不生成资源下载链接

### Requirement: 环境推广与回滚

系统 SHALL 仅允许获授权人员将已验收的同一制品推广到生产或回滚到保留版本。

#### Scenario: 测试推广

- **WHEN** 版本通过测试且发布人有生产权限
- **THEN** 生产绑定相同摘要并记录审计

#### Scenario: 未验收发布

- **WHEN** 版本缺失测试证据
- **THEN** 禁止生产推广并说明缺失项

### Requirement: 资源包安全校验

系统 SHALL 拒绝目录穿越、链接逃逸、摘要不匹配和超出配置限额的资源包。

#### Scenario: 合法目录

- **WHEN** 包内为限额内的规范相对路径
- **THEN** 可发布并保留目录结构

#### Scenario: 恶意归档

- **WHEN** 归档包含 ../、外部符号链接或解压后超限
- **THEN** 拒绝发布且不写出受控暂存目录

### Requirement: 保留与删除

系统 SHALL 保留部署中及审计保留期内任务引用的制品，并限制制品下载权限。

#### Scenario: 删除在用版本

- **WHEN** 版本仍被生产部署引用
- **THEN** 拒绝物理删除并提示引用关系

#### Scenario: 过期下载授权

- **WHEN** 下载凭证已过期或属于其他租户
- **THEN** 不返回制品内容
