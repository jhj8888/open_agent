# Spec Delta

## Purpose

模型部署与运维由专门团队承担，平台需要稳定使用其内网接口。应统一接口配置、凭据作用域、能力校验、超时与用量记录，避免把模型基础设施纳入 Agent 平台。 本能力用于定义企业内网 Agent 平台的可验证行为边界，使测试、部署、失败处理和权限控制具有一致的验收依据。

## ADDED Requirements

### Requirement: 环境模型配置

系统 SHALL 使用获授权租户和环境下的模型接口配置，不要求部署模型服务。

#### Scenario: 调用已有接口

- **WHEN** Agent 引用有效的内网 endpoint 和模型名
- **THEN** 通过 HTTP 调用该接口并返回结果

#### Scenario: 禁止跨环境引用

- **WHEN** 测试 Agent 引用未获授权的生产配置
- **THEN** 在调用前拒绝请求

### Requirement: 凭据与目的地址保护

系统 SHALL 仅在可信服务中解析凭据，并限制调用目的地址为管理员批准的模型接口。

#### Scenario: 凭据不出控制面

- **WHEN** 聊天界面或 Skill 查询运行配置
- **THEN** 只获得模型标识及脱敏信息，不能读取模型密钥

#### Scenario: 阻止地址绕过

- **WHEN** 接口地址重定向到未批准目的地或云元数据地址
- **THEN** 终止连接并记录脱敏安全事件

### Requirement: 调用能力匹配

系统 SHALL 在发布及调试前验证 Agent 所需的流式和工具调用能力。

#### Scenario: 工具调用兼容

- **WHEN** 模型返回有效结构化 tool_call 且 Agent 已授权该工具
- **THEN** 由平台校验参数后进入受控工具执行路径

#### Scenario: 不兼容模型

- **WHEN** 需要工具调用的 Agent 选择仅支持文本的接口
- **THEN** 给出明确配置错误且禁止发布该组合

#### Scenario: 管理页面验证实际工具往返

- **WHEN** 获授权用户验证启用流式和工具能力的模型连接
- **THEN** 按该配置的思考模式和版本分别验证流式文本、固定纯函数调用及结果回传，展示每步状态、耗时、服务端用量和脱敏错误
- **AND** 配置变更或权限撤销后停止后续验证请求，超时或失败不自动重放，缺少用量不记为零

#### Scenario: 仅声明文本能力

- **WHEN** 连接配置未启用工具能力
- **THEN** 文本验证成功也不会把工具能力标记为已验证，未执行步骤明确显示

### Requirement: 失败与取消

系统 SHALL 对超时、认证失败、限流和流中断返回可追踪错误，并在取消时停止后续调用。

#### Scenario: 上游限流

- **WHEN** 模型接口返回限流
- **THEN** 按明确的重试策略处理，最终任务状态和错误可查询

#### Scenario: 流中断取消

- **WHEN** 流式响应中断或任务被取消
- **THEN** 不自动重放非幂等工具操作并停止新的模型调用

### Requirement: 用量可观测

系统 SHALL 记录调用时延、结果和可获得的 token usage，缺失用量必须标为未知。

#### Scenario: 有用量响应

- **WHEN** 接口返回 usage
- **THEN** 记录与 run_id/租户/环境关联的输入输出用量

#### Scenario: 无用量响应

- **WHEN** 接口不返回 usage
- **THEN** 展示未知而非零，日志不记录凭据或默认记录完整提示词
