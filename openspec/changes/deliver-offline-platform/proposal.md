# Proposal

## Why

现有源码与 Helm 包仍包含公网镜像、在线资源和示例服务配置，不能直接等同于离线生产交付。平台需要可复现的内网制品、测试/生产隔离、持久日志统计和可操作的备份恢复流程。

## What Changes

- 提供 CPU 应用组件的离线构建/导入清单和锁定镜像，不包含模型基础设施。
- 测试与生产配置、凭据、存储、队列和发布流程隔离。
- 提供任务/沙盒/接口指标、租户授权日志查询、审计、告警与恢复手册。

## Capabilities

### New Capabilities

- `offline-platform-operations`: 离线交付、环境隔离与可观测性。

### Modified Capabilities

无。当前尚无已验收主规格；这是对现有代码的增量产品契约，不代表从零重写。

## Impact

源码依赖 → 构建机/内网制品库 → helm → 控制面/worker/沙盒依赖；服务 OTel/metrics → 内网采集与监控 → 平台统计 UI。复用已有企业网关、认证、存储和监控能力。

边界：不涉及模型网关、模型调度、推理部署或模型运维；复用已有模型 HTTP 接口。
