# Spec Delta

## Purpose

现有源码与 Helm 包仍包含公网镜像、在线资源和示例服务配置，不能直接等同于离线生产交付。平台需要可复现的内网制品、测试/生产隔离、持久日志统计和可操作的备份恢复流程。 本能力用于定义企业内网 Agent 平台的可验证行为边界，使测试、部署、失败处理和权限控制具有一致的验收依据。

## ADDED Requirements

### Requirement: 完整离线运行

系统 SHALL 在阻断公网的环境中完成安装、登录、Agent 发布、聊天、Skill 执行及日志查询，不依赖在线资源或 SaaS。

#### Scenario: 冷启动验收

- **WHEN** 已导入锁定制品且公网不可达
- **THEN** 全部核心流程成功并留下验证记录

#### Scenario: 缺失依赖

- **WHEN** 内网缺少必须镜像或依赖包
- **THEN** 预检明确报缺失项，不尝试公网下载

#### Scenario: Python 集群运行镜像离线构建

- **WHEN** 导入已锁定的基础镜像、完整目标平台 wheel 集合及经过校验的应用源码
- **THEN** 在无构建网络下完成依赖安装和镜像生成，启动使用已安装依赖；任一包缺失或摘要错误均失败关闭，不安装源码发行包或临时访问公网

#### Scenario: 镜像身份与敏感配置边界

- **WHEN** 以受限配置启动 supervisor 或 executor 镜像
- **THEN** 使用非 root 身份及只读应用文件，凭据仅通过运行时独立配置挂载提供，不进入镜像层、构建参数或分发清单

### Requirement: 测试生产隔离

系统 SHALL 隔离测试与生产的身份授权、凭据、数据、任务队列与制品发布绑定。

#### Scenario: 环境独立

- **WHEN** 测试环境执行故障任务
- **THEN** 不会读取或写入生产数据与队列

#### Scenario: 推广留痕

- **WHEN** 同一版本从测试推广生产
- **THEN** 保留摘要、测试证据、发布人和回滚目标

### Requirement: 日志与统计

系统 SHALL 提供租户授权的任务日志、状态和应用指标统计，默认脱敏敏感数据。

#### Scenario: 任务关联

- **WHEN** 用户查看获授权 run_id
- **THEN** 可关联状态、执行日志、trace 和可得模型调用用量

#### Scenario: 日志越权

- **WHEN** 用户通过搜索条件查询其他租户或未授权生产日志
- **THEN** 不返回受限日志或统计数据

#### Scenario: 完整时间窗口统计

- **WHEN** 获日志读取权限的成员选择最近 1 小时、24 小时或 7 天
- **THEN** 数据库统计该租户/环境窗口内全部任务，返回窗口与采样时间、状态分布、排队/执行耗时和已报告用量；未知用量保留未知，不截断为各部署最近 50 条

#### Scenario: 共享主机监控

- **WHEN** 平台管理员查看主机 CPU、内存、磁盘和组件健康
- **THEN** 后端仅查询预定义内部 Prometheus 指标；普通租户成员无权查询共享主机指标，指标源失效显示不可用或过期

#### Scenario: 指标采集权限与基数

- **WHEN** Prometheus 拉取平台指标
- **THEN** 仅专用只读服务身份可访问私有采集端点；指标标签只含有限环境、状态和组件枚举，不包含租户 ID、run_id、输入、输出或密钥

### Requirement: 可恢复运维

系统 SHALL 提供健康检查、告警、备份和恢复过程，并在真实演练中验证任务与制品可恢复。

#### Scenario: 依赖故障告警

- **WHEN** 任务长期排队、worker 失联或沙盒回收失败
- **THEN** 触发可定位到平台组件的告警

#### Scenario: 恢复演练

- **WHEN** 从受控备份恢复到隔离环境
- **THEN** 核验配置、制品、任务和审计完整性并记录实际恢复指标

#### Scenario: 一致性备份与恢复边界

- **WHEN** 执行展示环境备份或隔离恢复演练
- **THEN** 备份前拒绝活动任务与未释放尝试，协调停止项目写入端并备份完整任务/文件/观测数据及所需密钥；备份失败恢复原服务状态，隔离恢复不修改线上数据或重新执行任务，记录数据截点、停机时间及实测恢复时间

#### Scenario: 备份保密与完整性

- **WHEN** 备份仓库被复制到另一台已授权的设备
- **THEN** 仓库保持加密，解密密钥单独受保护；恢复前验证仓库完整性，损坏或缺失输入不得报告恢复成功

### Requirement: 可审计交付边界

系统 SHALL 交付锁定版本、SBOM、许可范围及摘要清单，且只引用模型 API，不包含模型网关、推理或 GPU 调度服务。

#### Scenario: 交付审查

- **WHEN** 审查部署清单和安装产物
- **THEN** 可追溯每个组件来源、版本、许可且没有新增模型基础设施

#### Scenario: 制品被修改

- **WHEN** 导入包摘要与交付清单不一致
- **THEN** 预检拒绝使用该包

#### Scenario: 控制面交付增量

- **WHEN** 仅交付控制 API 与工作台的 Kubernetes 部署包而集群执行器尚未接通
- **THEN** 明确标识交付范围并强制关闭新任务准入，拒绝通过配置绕过；渲染检查与容器验证不作为实际集群、CNI 或完整离线验收的替代

#### Scenario: 镜像引用导入

- **WHEN** 操作者为部署包登记已导入内网仓库的镜像
- **THEN** 核对实际 manifest digest 与已验收镜像的对应关系，不把本地 config ID 或镜像归档摘要当成可拉取的镜像 digest；缺失或不匹配时失败关闭
