# Spec Delta

## Purpose

企业共享同一平台，需要把人员、Agent、Skill、任务、日志和凭据的访问统一到可信租户边界。现有空间成员检查可以复用，但不能据此推断所有运行时资源已隔离。 本能力用于定义企业内网 Agent 平台的可验证行为边界，使测试、部署、失败处理和权限控制具有一致的验收依据。

## ADDED Requirements

### Requirement: 首次登录登记

系统 SHALL 使用已验证 OIDC 身份登记本地账号，默认不分配租户、角色或生产执行权限。

#### Scenario: 新员工首次访问

- **WHEN** 已认证但尚未登记的用户进入工作台
- **THEN** 幂等登记其 JWT subject 并显示账号标识，供管理员显式添加成员

#### Scenario: 禁用及身份冲突

- **WHEN** 登记请求对应已禁用、已删除账号或仅数据库排序规则视为相同的其他 subject
- **THEN** 拒绝登记，不重新激活账号、不覆盖已有资料、不授予任何权限

#### Scenario: 伪造登记身份

- **WHEN** 调用方通过请求头或请求体指定其他用户或角色
- **THEN** 仅采用已验证 JWT subject，未认证请求返回 401

### Requirement: 可信租户上下文

系统 SHALL 从有效身份及成员关系解析租户、环境和角色，并拒绝客户端伪造的资源归属。

#### Scenario: 合法成员访问

- **WHEN** 成员访问其被授权租户的测试资源
- **THEN** 返回该租户测试环境的数据

#### Scenario: 跨租户访问

- **WHEN** 租户 A 成员提交租户 B 的资源 ID 或 tenant_id
- **THEN** 拒绝访问且不暴露 B 的资源是否存在

### Requirement: 成员与角色管理

系统 SHALL 允许获授权管理员管理租户和成员角色，并阻止普通成员提升自身权限。

#### Scenario: 管理员分配角色

- **WHEN** 租户管理员为本租户成员分配开发者角色
- **THEN** 保存生效并记录操作者与变更

#### Scenario: 禁止自行提权

- **WHEN** 开发者调用角色修改接口将自己改为管理员
- **THEN** 返回授权错误且角色不变

#### Scenario: 保留可用管理员

- **WHEN** 管理员移除或降级最后一个仍可进入该环境的管理员，而其他管理员账号已禁用或已离开旧空间
- **THEN** 拒绝变更，不把失去实际成员资格的账号计入可用管理员数量

### Requirement: 环境权限隔离

系统 SHALL 分别授权测试与生产资源、发布操作及服务凭据。

#### Scenario: 测试权限受限

- **WHEN** 只有测试权限的开发者访问生产日志或执行生产部署
- **THEN** 拒绝请求且不返回生产配置

#### Scenario: 受权发布

- **WHEN** 有生产发布权限的运维发布已经验收的版本
- **THEN** 允许操作并记录发布审计

### Requirement: 租户生命周期

系统 SHALL 支持停用租户并禁止新任务；已接收任务按明确策略完成或由管理员取消。

#### Scenario: 停用后提交

- **WHEN** 停用租户尝试提交新的任务
- **THEN** 拒绝提交且不创建沙盒

#### Scenario: 保留历史

- **WHEN** 租户被停用但任务仍在审计保留期内
- **THEN** 获授权管理员仍可查询历史和取消存量任务

#### Scenario: 暂停后完成已接收任务

- **WHEN** 租户暂停前已经持久接收任务，任务处于排队或运行状态
- **THEN** 允许其依原配额继续领取、续约、读取绑定配置、执行模型/工具、记录步骤和产物及提交完成，不因暂停本身转为失败
- **AND** 新提交仍被拒绝，显式取消、租约过期、截止时间、绑定版本撤销及错误 worker 身份仍能阻止后续执行，归档状态不继承此许可

### Requirement: 配额与审计

系统 SHALL 允许管理员配置租户的任务并发、队列、沙盒及调用预算上限，并审计权限、配额与凭据变更。

#### Scenario: 调整配额

- **WHEN** 管理员降低配额至低于当前占用
- **THEN** 保留现有任务并禁止继续超额接入，展示占用与新上限

#### Scenario: 查看每日任务用量

- **WHEN** 获授权成员查看当前租户和环境的配额
- **THEN** 按北京时间自然日和模型调用结束时间，展示截至采样时刻的任务模型输入、输出、缓存与新增输入，以及已知合计
- **AND** 不重复累计父步骤，不因任务取消或删除扣回历史用量；单独展示未知 usage 和尚未结束的调用，缓存未知不填零，不把已知合计误称为完整消耗或已执行预算限制
- **AND** 返回日期、时区和采样边界，说明模型连接诊断不属于任务用量，跨租户和未授权环境拒绝查询

#### Scenario: 审计脱敏

- **WHEN** 管理员轮换服务凭据
- **THEN** 审计可追溯操作者和版本但不包含凭据明文

#### Scenario: 查询完整审计历史

- **WHEN** 获授权管理员查询超过一页的当前环境审计或按操作类型筛选
- **THEN** 可分页读取保留记录并查看操作者、变更前后值和保留截止时间，每页重新执行权限检查
