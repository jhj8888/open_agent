# Spec Delta

## ADDED Requirements

### Requirement: 真实认证与租户范围

工作台 SHALL 使用 OIDC 授权码 PKCE 登录，按用户实际权限显示租户与环境，并在切换范围时清除旧任务与配置数据。

#### Scenario: 切换租户

- **WHEN** 用户从租户 A 切换到租户 B
- **THEN** 停止 A 的订阅并只展示 B 授权范围内的数据

#### Scenario: 刷新令牌过期

- **WHEN** 身份服务明确拒绝刷新过期或撤销的令牌
- **THEN** 清除内存会话、终止旧范围订阅并显示重新登录入口，不回显原始身份错误或自动重放操作

### Requirement: 持久聊天与任务

工作台 SHALL 使用统一 Agent HTTP API 创建、读取、订阅和取消任务，所有结果与状态由后端持久记录提供。

#### Scenario: 断线重连

- **WHEN** 任务执行期间浏览器断线后恢复
- **THEN** 按事件序号续读同一任务，不重复提交执行

### Requirement: 可检索的完整任务历史

工作台 SHALL 分页查询当前租户与环境的全部保留任务，支持按任务 ID 前缀、Agent 名称和任务状态筛选，不受部署列表或每部署最近任务数量限制。每页 SHALL 重新授权，生产部署受委派成员仅能读取仍获授权部署中自己提交的任务，已删除任务不展示。

#### Scenario: 历史任务超出首页

- **WHEN** 单个部署超过 50 个任务或环境超过 100 个部署
- **THEN** 用户仍能分页找到有权访问的旧任务，并打开详情查看步骤及下载保留的产物

#### Scenario: 翻页期间权限或列表变化

- **WHEN** 用户翻页时新增任务、原页末任务删除，或成员/部署授权被撤销
- **THEN** 使用创建时间与任务 ID 的稳定边界继续查询，重新执行当前权限校验，不因游标持有旧授权；切换范围或筛选时取消旧查询并清空旧页

### Requirement: 真实管理操作

工作台 SHALL 支持版本化 Skill 上传、模型配置、Agent 测试部署与部署凭据管理，并遵守服务端生产发布门禁。

#### Scenario: 模型凭据保护

- **WHEN** 用户保存模型接口密钥
- **THEN** 页面不回显已保存密钥，构建文件和浏览器持久存储不包含该密钥

#### Scenario: 管理表单本地校验失败

- **WHEN** Agent 创建、Skill 上传或其他管理表单在发起 API 请求前校验失败
- **THEN** 保留用户输入、显示错误并恢复提交按钮，不将失败展示为成功；同一表单请求尚未结束时不重复提交

### Requirement: 可验证展示入口

展示入口 SHALL 保留已认可的视觉风格，通过 HTTPS 提供实际工作台，拒绝公开访问内部调度与执行监督接口。

#### Scenario: 内部路由访问

- **WHEN** 公网客户端请求内部 worker 或 reconciler 路由
- **THEN** 入口拒绝请求，不转发到控制面

### Requirement: 统计与错误真实性

工作台 SHALL 使用真实任务和服务数据展示统计，不能将示例数值、模拟回答或失败请求展示为成功。

#### Scenario: 服务不可用

- **WHEN** 控制面请求失败
- **THEN** 显示可恢复的错误状态并保留合法重试语义，不生成示例结果

#### Scenario: 列表用量统计

- **WHEN** 用户读取部署的最近任务列表
- **THEN** 列表返回与单任务详情一致的持久用量，缺失用量为 null，不计为零
