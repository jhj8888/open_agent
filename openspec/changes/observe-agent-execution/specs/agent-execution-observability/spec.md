## ADDED Requirements

### Requirement: 可关联的完整执行过程

系统 SHALL 将每个任务的输入/上下文感知、Skill 选择、模型调用、工具行动和产出步骤记录为可关联的父子步骤，展示已授权日志、状态、时序与可得决策摘要。

#### Scenario: 多步并发任务

- **WHEN** 两个任务并发执行多个模型与工具步骤
- **THEN** 每个步骤关联正确 run、attempt 和父步骤，时间线显示各自输入输出摘要、状态与持续时间，不串用任务信息

#### Scenario: 中断或旧数据

- **WHEN** 任务在步骤中断或历史任务没有采集逐步信息
- **THEN** 界面明确标记中断/未记录，不生成虚构步骤、模型推理或完成状态

### Requirement: 步骤增量正文和模型思考字段

系统 SHALL 在任务权限下展示每步新增输入、模型实际返回的思考字段或思考摘要、工具参数与调用结果、步骤输出；在持久化前执行凭据脱敏和内容容量限制。不存在或未采集的字段必须明确标记，不能从最终回答推造思考过程。

#### Scenario: 连续模型与工具调用

- **WHEN** 一次模型调用发出工具调用，工具执行返回结果并触发下一次模型调用
- **THEN** 原模型步骤显示其实际思考/回答/工具请求，工具步骤显示参数和结果，下一模型步骤显示相对于先前上下文新增的消息，并保留消息角色与工具调用关联

#### Scenario: 上下文重置与长内容

- **WHEN** 框架压缩或分支使输入无法与上次上下文作前缀匹配，或内容超过记录容量
- **THEN** 明确标注初始/追加/上下文变化及截断，不误标全部历史为新增；已归档文件仍通过授权产物接口查看下载

#### Scenario: DeepSeek 思考协议

- **WHEN** 可信模型配置选用 DeepSeek 适配器及思考模式
- **THEN** 使用官方 ChatDeepSeek SDK 保留流式 reasoning_content 与工具对话协议，沿用原有模型网络准入/租约/凭据边界；默认通用配置保持原行为

### Requirement: 逐步可信计量

系统 SHALL 提供每步耗时及模型直接输入/输出/缓存 Token 与计量来源，并避免父子聚合重复记账。

#### Scenario: 纯工具与缺失模型用量

- **WHEN** 一个工具没有模型调用，而另一个模型调用没有返回 usage
- **THEN** 前者直接 Token 为 0，后者为未知；估算与 provider 实测值区分展示

#### Scenario: 上报重复与业务重试

- **WHEN** 同一调用事件重复投递，另有一次真正发生的模型重试
- **THEN** 重复事件只计一次，实际重试的独立调用计入用量，父步骤汇总不再次相加

#### Scenario: 缓存命中与新增输入

- **WHEN** 模型调用报告输入总量及缓存命中 Token
- **THEN** 步骤摘要展示输入总量、缓存命中和新增（未命中缓存）Token，新增等于输入减缓存命中且不把缓存写入重复加到输入；缺少缓存明细时缓存与新增均显示未知

#### Scenario: 部分缓存明细的任务与周期汇总

- **WHEN** 同一任务或自然周/月中只有部分模型调用报告缓存明细
- **THEN** 分别汇总已报告的缓存及其对应新增量，显示未知明细调用数；任务总计不受步骤分页影响，每日表和 CSV 保留缺失语义，不用完整输入总量减部分缓存总量伪造新增量

### Requirement: 自然周月统计

系统 SHALL 提供本周、上周、本月、上月统计和导出，明确时区、半开时间区间及任务/调用归属口径。

#### Scenario: 月界和跨周期任务

- **WHEN** 一个任务在月末创建并在下月完成模型调用
- **THEN** 创建数量与调用用量分别按约定时间归属正确月份，不用最近 30 天代替自然月，不遗漏或重复边界记录

### Requirement: 租户权限与私有采集

系统 MUST 在服务端校验步骤、日志和统计的租户/环境授权，保护采集凭据，并只把脱敏数据发送到配置的私有观测端点。

#### Scenario: 伪造关联或直接查询

- **WHEN** 用户提交其他租户的 task、trace 或 step 标识
- **THEN** 服务端拒绝访问，浏览器得不到共享后端密钥或绕过授权的链接

#### Scenario: 观测服务宕机

- **WHEN** 私有观测后端不可用或执行进程被终止
- **THEN** 受限重试/持久投递记录呈现故障或缺口，恢复不重放模型/工具副作用，不伪造未获得的计量

#### Scenario: 迟到回调与投递租约

- **WHEN** 已领取的观测快照出现新的结束回调，或导出器在确认前被终止
- **THEN** 新 revision 不能被旧确认覆盖；仅认证的领取者可以读取与确认有效租约，过期记录可再次领取；相同 trace/span 标识的补发不会重复计算 Token

#### Scenario: 独立后端访问边界

- **WHEN** 观测后端部署在演示服务器或内网
- **THEN** 后端凭据仅独立导出器持有，浏览器和任务 worker 无法通过导出身份读取模型密钥或发起执行；平台的租户权限、自然周期口径和文件生命周期继续独立执行
