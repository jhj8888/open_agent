## ADDED Requirements

### Requirement: 可关联的完整执行过程

系统 SHALL 将每个任务的输入/上下文感知、Skill 选择、模型调用、工具行动和产出步骤记录为可关联的父子步骤，展示已授权日志、状态、时序与可得决策摘要。

#### Scenario: 多步并发任务

- **WHEN** 两个任务并发执行多个模型与工具步骤
- **THEN** 每个步骤关联正确 run、attempt 和父步骤，时间线显示各自输入输出摘要、状态与持续时间，不串用任务信息

#### Scenario: 中断或旧数据

- **WHEN** 任务在步骤中断或历史任务没有采集逐步信息
- **THEN** 界面明确标记中断/未记录，不生成虚构步骤、模型推理或完成状态

### Requirement: 逐步可信计量

系统 SHALL 提供每步耗时及模型直接输入/输出/缓存 Token 与计量来源，并避免父子聚合重复记账。

#### Scenario: 纯工具与缺失模型用量

- **WHEN** 一个工具没有模型调用，而另一个模型调用没有返回 usage
- **THEN** 前者直接 Token 为 0，后者为未知；估算与 provider 实测值区分展示

#### Scenario: 上报重复与业务重试

- **WHEN** 同一调用事件重复投递，另有一次真正发生的模型重试
- **THEN** 重复事件只计一次，实际重试的独立调用计入用量，父步骤汇总不再次相加

### Requirement: 自然周月统计

系统 SHALL 提供本周、上周、本月、上月统计和导出，明确时区、半开时间区间及任务/调用归属口径。

#### Scenario: 月界和跨周期任务

- **WHEN** 一个任务在月末创建并在下月完成模型调用
- **THEN** 创建数量与调用用量分别按约定时间归属正确月份，不用最近 30 天代替自然月，不遗漏或重复边界记录

### Requirement: 租户权限与私有采集

系统 MUST 在服务端校验步骤、日志和统计的租户/环境授权，保护采集凭据，并只把脱敏数据发送到配置的私有观测端点。

#### Scenario: 伪造关联或直接查询

- **WHEN** 用户提交其他租户的 task、trace 或 step 标识
- **THEN** 服务端拒绝访问，浏览器得不到共享后端密钥或绕过授权的链接

#### Scenario: 观测服务宕机

- **WHEN** 私有观测后端不可用或执行进程被终止
- **THEN** 受限重试/持久投递记录呈现故障或缺口，恢复不重放模型/工具副作用，不伪造未获得的计量
